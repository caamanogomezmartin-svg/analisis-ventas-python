# Análisis de ventas con Python

Proyecto de análisis de datos con Python y pandas sobre 3.000 pedidos simulados de una tienda de ropa streetwear durante 2025.

## Preguntas de negocio
- ¿Cómo evolucionan las ventas a lo largo del año?
- ¿Qué categorías y productos generan más ingresos?
- ¿Qué canal de venta funciona mejor?
- ¿Compensan los descuentos?

## Conclusiones principales
- Diciembre es el mejor mes y febrero el peor.
- Sudaderas y pantalones suman más del 55 % de los ingresos.
- Las zapatillas son el producto que más factura, gracias a su precio alto.
- La web aporta casi la mitad de los ingresos e Instagram va segundo.
- En los meses con descuento hubo un 46 % más de pedidos y un 16 % más de ingresos al mes.

## Archivos
- `analisis_ventas.ipynb`: notebook con el código, los gráficos y las conclusiones.
- `ventas_2025.csv`: datos utilizados en el análisis.
